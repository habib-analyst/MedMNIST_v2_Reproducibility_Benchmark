# Execution evidence and compute status

The retained 2D experiment evidence in this repository was produced on a Kaggle GPU notebook. The 3D runner notebook is prepared but has not been executed.

## Available evidence

- `gpu_partial_27epoch_record`: checkpointed execution at 27/100 epochs; paused because the session budget could not start another epoch.
- `gpu_historical_32epoch_attempt`: separate historical execution at 32/100 epochs.

## Timing

- Measured 2D speed: approximately 1,325–1,341 seconds per epoch.
- Extrapolated 100-epoch duration: approximately 36.8–37.3 GPU-hours.
- 3D timing and peak VRAM: not measured.

## Why the full protocol is pending

Free GPU session and weekly compute limits were insufficient for the full 2D/3D protocol. The available results are therefore partial, retained for audit, and not presented as completed official results.

## Notebook provenance

`runner/medmnist_3d_suite_kaggle.ipynb` is a hand-prepared 3D-suite variant derived from the notebook templates generated by `scripts/build_runner_notebooks.py`; it is not a direct output of that builder. It has not been executed.
